Insolvent Strategy

Your personal automated trading strategy. Every cycle it checks BTC's position relative to its 7-day high and manages two sides simultaneously:

Short side — if BTC is within the short zone of its 7d high, checks if any short-asset pumped ≥7% in 24h. If yes, opens a market short. Adds to losing shorts up to 3 ladder entries.

Long side — if BTC is within the long zone of its 7d low, opens new market longs on your long-assets. Also manages existing longs: if down 5% from entry → adds; if BTC pumped 2%+ then went flat → closes 25% and places a limit re-entry at your original entry price.

Max Capital %Max % of account value in open positions across all assets. E.g. 30 = never exceed 30% deployed.
Short Zone %How close BTC must be to its 7-day high to enable shorting. 0.5 means within 0.5% of the high.
Long Zone %How close BTC must be to its 7-day low to trigger new long entries. 0.5 means within 0.5% of the low.
Check IntervalMinutes between each full strategy cycle. 1 = checks every minute.

DCA Bot

Dollar Cost Averaging. Two modes: Time — places a fixed order on a schedule. Drop — only buys when price falls by at least the specified % from your last buy. Ideal for building a position gradually. Stops when max orders is reached.

CoinAsset to trade. E.g. BTC, SOL, ETH.
SideLong = buy. Short = sell.
Order SizeAmount per order. Toggle between USD or tokens.
ModeTime = buy every N minutes. Drop = buy only when price dips X% from last buy.
Drop %Drop mode only — % price must fall from last buy to trigger next order.
IntervalTime mode: minutes between orders. Drop mode: how often to check price.
Max OrdersTotal orders before the bot stops. 0 = run forever.
LeveragePosition leverage. 1 = no leverage. Use with care.

Grid Bot

Places a ladder of buy and sell limit orders between a lower and upper price. When a buy fills, it places a sell one level up. When a sell fills, it places a buy one level down. Collects profit from each completed cycle. Best in sideways, oscillating markets.

CoinAsset to trade.
Lower / Upper PriceThe price range the grid covers. Set it around the current price.
Grid LevelsHow many price intervals to divide the range into. More levels = smaller steps = more frequent fills.
Size per LevelHow much to allocate to each grid order. Toggle USD or tokens.
LeveragePosition leverage. Grid bots typically work best at 1x.

Trend Follower

Uses two Exponential Moving Averages (EMAs) to detect trend direction. Goes long when the fast EMA crosses above the slow EMA. Goes short when it crosses below. Automatically closes the previous position and opens the new one.

CoinAsset to trade.
Fast EMAShorter period — reacts quickly. E.g. 9 = average of last 9 candles. Lower = more signals.
Slow EMALonger period — smoother, slower. E.g. 21. Must be higher than Fast EMA.
Position SizeUSD or tokens per position. Full size is opened on each signal.
LeverageHigher = larger gains and losses per signal.
Check IntervalMinutes between EMA recalculations. Lower = more responsive but more API calls.
Stop-Loss %0 = hold through losses until signal flips. Set a % to force-close if loss exceeds it.

Longer Bot

Opens long positions on a list of coins and manages them automatically. Always mode longs everything in the list. Dump mode only enters longs when a coin has fallen below the threshold (buy the dip). Each position is closed at take-profit or stop-loss independently.

CoinsComma-separated list of assets to long. E.g. BTC,ETH,SOL.
SizeUSD (or tokens) per position. Each coin gets this allocation.
TriggerAlways = long immediately. Dump = wait for coin to drop X% before longing.
Dump % + WindowMinimum drop % over the selected time window. E.g. 7% / 1w = long if down ≥7% this week.
Take ProfitClose the long when price rises this % (or hits the $ price) from entry. Logs a WIN.
Stop LossClose the long if price drops this % (or hits the $ price) from entry. 0 = disabled.
Check IntervalMinutes between each cycle. Lower = faster TP/SL response.

Custom Bot

Run any Node.js script as a managed strategy. Your agent key is injected automatically as --wallet. The script runs in a child process so it doesn't block the dashboard, and its output streams live into the Logs panel.

Your script receives the same environment as the built-in strategies. Use the same ExchangeClient + ethers.Wallet pattern and read --wallet from args.

Script PathRelative path from the project root. E.g. strategies/my-bot.js.
CoinPassed as --coin to your script. Leave blank to omit.
LeveragePassed as --leverage. Leave blank to omit.
